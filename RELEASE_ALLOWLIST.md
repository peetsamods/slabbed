# Release archive allowlist

The release archives are closed worlds: every entry in each archive must appear
in its fenced list below, and every listed entry must be present. Enforced by
`tools/verify-release-allowlist.py`, run from the build for each artifact.

On this line the artifact players install is the **`-all` jar** - it is the only
archive carrying the MixinExtras jar-in-jar payload, which Forge 1.20.1 does not
bundle. The bare runtime jar is listed as its own closed world too, so drift in
either is caught.
